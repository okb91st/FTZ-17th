# FTZ-17th

Official website and project archive of FTZ-17th.

FTZ-17th is an independent model design and technical drawing project.  
This website provides project updates, archived works, design information, and links to FTZ-17th content.

## Website

The website is currently under development.

Planned sections:

- Home
- Projects
- Archive
- Community
- Bilibili

## Archive System

The archive will support searchable categories and tags, including:

- Country / Region
- Historical Period
- Ground / Air / Naval
- Vehicle Type
- Custom / Standard Production
- Series and Collection Tags

Examples:

`Leopard 2 Series` · `East Germany` · `T-72 Series`

## News

News will be updated regularly with:

- Upcoming releases
- Weekly project plans
- Video release summaries
- Project updates
- Website announcements

## Development

The first version of the website uses:

- HTML
- CSS
- JavaScript
- JSON

The structure is designed to allow future backend integration.
